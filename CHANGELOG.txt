CHANGELOG - Android Firmware Full Toolkit (AFFT)
===========================================

v2.0.2 (2026-06-12)
-------------------

[!] Perbaikan Bug:
    - Fix raw_to_sparse struct.pack format mismatch: "<IHHIIIII" (8 spec, 9 args)
      diganti "<IHHHHIIII" (9 spec, 9 args) agar konversi sparse tidak error
    - Fix raw_to_sparse uint32 overflow untuk image >4GB:
      Sekarang support multi-chunk RAW (split jadi beberapa chunk) untuk image
      besar seperti product.img (4.8GB), bukan cuma fallback ke raw
    - Fix stray "continue" tanpa kondisi di main.py repack loop:
      Semua direktori ke-skip karena continue doang → repack selalu "Semua gagal"
    - Fix "Semua filesystem gagal direpack" karena direktori ext4 hanya berisi
      subfolder "ext4_extract/" (file tidak langsung di root folder)
    - Fix SIGSYS crash untuk partisi firmware: 42 partisi non-filesystem
      (abl, aop, modem, tz, xbl, dll) sekarang di-skip dengan pesan jelas

[+] Fitur Baru:
    - Wizard mode [W]: Auto-scan folder untuk .img & content directories,
      lalu kasih pilihan unpack/repack dengan path kustom
    - Debug mode [D]: Toggle global, semua module tampilkan info detail
      (filesystem detected, mkfs command, lpunpack params, dll)
    - Perbaikan file detection: unpack_filesystem & repack_filesystem
      otomatis skip 42 partisi firmware yang bukan filesystem

[*] Peningkatan:
    - Output konsisten: unpack_filesystem bersihkan dulu folder sebelum
      ekstrak (if out_dir.exists(): shutil.rmtree(out_dir))
    - Error handling: semua exception cleanup dengan rmtree (full & partial)
    - DEBUG flag pindah ke modules/common.py supaya bisa diakses semua module
    - Menu display debug status pakai module reference (bukan local copy)
