# Helper Binaries

This directory is intentionally kept out of version control for the source-only
release.

If you want to run the toolkit locally, place the required helper binaries here
with the expected filenames:

- `payload-dumper-go`
- `lpunpack`
- `simg2img`
- `extract.erofs`
- `debugfs`

Each binary must come from its legitimate upstream source and should be checked
against its own redistribution terms before sharing.
